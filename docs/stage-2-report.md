# 横屏 Noval 首版实现与验证 · 0.2.0

日期：2026-10-07。已在独立验证实例 `http://192.168.31.201:32012` 接入真实酒馆运行时。此版是可交互、可保存的工作台实现，不是静态预览；生产端口 `32001` 未更新。

## 实现与设计对应

- 确认稿：`docs/design/novel-desktop/` 与 `docs/design/desktop-details/`。横屏主页、纸张配色、四项快捷配置、默认收起的右栏、世界书四区编辑和角色管理沿用确认稿。
- 补充设计：`docs/design/desktop-details/resource-editors.md`。连接、预设、Persona 的独立页面采用资源列表 + 编辑区；这部分是本轮实现方案，仍可根据实际体验调整视觉。
- TypeScript + React，单一前端扩展，世界书、角色、资源编辑、Trace 分包加载；Lucide 图标打包在本地，不依赖图标 CDN。
- `themes/noval-paper.json` 与 `themes/noval-paper.css` 提供原生主题导入产物。插件提供默认外观并读取 `--wb-theme-*` 变量，布局与交互不依赖主题脚本。
- 审阅了已有 `story-workspace` 的 README、设计说明与加载入口，采用相同的原生节点保留原则；未把其 Vue 运行时合并进本扩展，也未改动其生产部署资产。

## 数据与兼容接入

**原生聊天与输入**：以 CSS 重排 `#sheld`、`#chat`、`#form_sheld`，不搬移或克隆消息和输入节点。React 只管理工作台及新增控件，在两个原生工具按钮内附加可撤销的图标。工具栏调用原生操作，附件通过 `#attachFile` 进入原生文件处理链路。全屏输入使用同一个 textarea。

**宿主适配**：优先使用 `getContext()`；1.19.0 相关内部模块、DOM 选择器和官方 API 均集中在 `src/host/`。适配失败、渲染失败、窄屏或重复工作台冲突时保留原生入口。键盘和按钮复用操作注册与业务方法。

**资源保存**：

- 世界书复用官方 `/api/worldinfo/get`、`/api/worldinfo/edit`。官方 `saveWorldInfo()` 在当前版本不检查 HTTP 状态，因此适配层显式检查响应后再更新官方缓存并发出 `WORLDINFO_UPDATED`。
- 世界书全局启用通过原生选择器写入数字索引；浏览下一本不替换启用列表。激活方式与 disable 字段独立。
- 角色使用官方读取、合并、PNG 导出、删除接口；按字段提交改动，保留未知扩展字段。批量操作逐项提交，失败会中止后续操作，不宣称事务回滚。
- 预设使用原生 PresetManager；连接选择使用原生 Connection Manager；Persona 使用原生状态与保存路径。配置、名称、模型编辑不会重新存储密钥。
- 世界书及角色、预设编辑对比基线、草稿、最新数据；冲突时拒绝覆盖并保留草稿。未编辑字段保留最新值。保存期间禁用编辑，防止保存响应覆盖新输入。外部更新在无未保存修改时同步。
- Persona 和连接设置保存等待原生 `SETTINGS_UPDATED` 确认；失败保留草稿并撤销本次临时内存赋值。原生设置仍使用其文件保存机制；布局偏好、模型分组、绑定等即时偏好沿用原生防抖保存与错误提示。

**Trace**：复用第一阶段观察器。区分组装事件与浏览器实际 POST，显示已观察到的世界书激活；不声称展示服务端最终请求或完整未命中原因。只保留 20 条内存记录，正文快照上限 128 KiB，排除认证字段，不消费 SSE 正文。

## 性能测量

1440×900、同一主机、同一合成数据。每组 5 个冷浏览器上下文，每次再执行一次热缓存导航；服务端缓存保留。用官方 APP_READY 区分酒馆就绪，以工作台完成挂载并经过绘制帧记录界面就绪。

| 组合 | 冷缓存 APP_READY 中位数 | 热缓存 APP_READY 中位数 | 冷 / 热工作台界面就绪中位数 |
| --- | ---: | ---: | ---: |
| 原生，助手与工作台停用 | 2.392 s | 2.094 s | — |
| 工作台 | 2.372 s | 2.133 s | 2.463 / 2.181 s |
| 酒馆助手 + 工作台 | 2.798 s | 2.363 s | 2.926 / 2.437 s |

样本范围重叠，不据此声称提速。普通前端扩展无法优化执行前的官方初始化；本轮没有启用 Early Bridge、核心补丁或 Service Worker。

长聊天单独使用 400 条内存合成消息，每组 3 个浏览器会话。保留官方 chat_truncation=100，实际渲染最近 100 条；设置与聊天保存请求被测试工具拦截，临时数据不落盘，不测模型延迟。

| 指标 | 原生 + 助手 | 工作台 + 助手 |
| --- | ---: | ---: |
| 渲染中位数 | 319 ms | 364 ms |
| 各次平均滚动帧间隔 | 16.23–16.38 ms | 16.38–16.62 ms |
| 本次采样堆内存增量 | 约 3.54–3.77 MB | 约 7.68–7.78 MB |

工作台增加大纲和外围组件，存在可见的额外渲染与内存成本。堆增量受 GC 影响，三次采样不能证明不存在内存泄漏；反复挂载的事件监听数量另行核对稳定。上述数据不代表生产规模或真实移动设备。
