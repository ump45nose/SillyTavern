# Novel / RP 手机工作台

实际酒馆入口：http://192.168.31.201:32012/ 。使用现有账号，刷新后生效。窗口小于 1024 CSS 像素时使用手机布局；更宽窗口继续使用原有桌面布局。顶栏三点菜单切换 Novel / RP / 原生，回到原生后仍可通过工作台切换控件进入。

## 确认稿检查

采用 `docs/design/novel-pwa/` 和 `docs/design/rp-pwa/` 已确认的布局与交互。确认稿是 390×844 的手机模型，外层预览还扣除了 32px 宽度，不能直接用于实际视口。实际实现不显示模拟状态栏、手机边框和底部系统横线，使用 `visualViewport`、`dvh` 和安全区。图标使用项目本地 Lucide，运行页面不依赖预览的外部图标 CDN。

## Novel

- 顶部保留导航、角色与会话、三点管理。左右边栏默认收起；正文右滑打开导航，左滑打开角色与资源，反向滑动或关闭按钮收起。
- 输入框内的连接、预设、世界书、用户设定默认收纳为快捷配置摘要。资源选择、启用、下一个及详情复用桌面行为。
- 菜单、扩展、续写、重生成、快速回复、附件及用户固定的工具沿用原功能；空间不足时进入“更多工具”。
- 点击或上拉输入框横线进入全屏草稿，返回保留文字和输入位置。字体和阅读设置位于三点管理菜单。

## RP

- 默认显示按楼层排列的聊天气泡，底部仅加号、输入框、发送按钮。加号包含快捷配置、附件、原生工具及全屏输入。
- 轻点角色栏切换立绘；拖动顶栏让整个聊天面板跟手下移，再向上拖动复位。使用当前角色的原生表情立绘或聊天配置的立绘，不改角色数据。
- 长按最新角色回复，打开编辑、复制、候选回复、生图及 Trace。操作使用原生消息控件；侧滑导航不会同时切换候选回复。
- 手动生图仍使用原聊天输入框，支持已有参考图操作，退出后恢复聊天草稿。

## 复用和边界

聊天、输入、发送和消息附件节点保持原样，模型请求与数据保存继续走酒馆链路。左右资源栏、大纲、记录导出、生图和完整设置页复用既有组件；手机只调整排列、宽度和入口。宽度变化和桌面 / 手机布局切换不会卸载宿主或取消附加任务。关闭工作台仍沿用既有任务清理。

沿用酒馆现有 manifest 与启动方式，没有新增服务或离线缓存。使用可见视口适应软键盘、页面偏移及安全区；安装后的 iOS / Android 真机键盘、系统侧滑和全面屏安全区仍需设备验证，桌面浏览器模拟不能替代这项验证。
