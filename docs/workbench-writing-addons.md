# 大纲与生图附加功能

实际酒馆验证入口：http://192.168.31.201:32012/ 。刷新后载入新代码。
设计预览：http://192.168.31.201:33080/sillytavern/addons/ 。预览模拟操作，不访问模型或聊天数据。

在「扩展 → 工作台附加功能」管理开关。大纲和生图默认启用入口，自动写作和自动生图默认关闭。打开入口或命中已开启的自动规则时才加载业务代码。两项功能共用 Noval / RP，没有输入框底部入口。

## 大纲

展开左栏「大纲」查看当前聊天的树。章节箭头逐层展开；叶节点箭头展开内容摘要。点击名称在右栏操作选中节点，右上展开按钮打开完整编辑页。

展开大纲时自动收纳左栏下方的设置组件，将空间交给大纲树。「展开设置」临时展开原设置入口及快捷键；「进入设置页」直接打开现有独立设置工作区。收起大纲后恢复原设置区；重新展开大纲时再次默认收纳设置。

- 支持新建同级/子节点、复制、删除，搜索标题和正文。拖动到目标节点前方排序，按住 Shift 拖入节点。方向键选择和展开树。选中节点有边框和浅底色；状态使用实心圆。
- Markdown 内容在编辑页修改、预览并保存。离开未保存编辑页会被阻止，先保存或撤销草稿。JSON 交换完整结构、状态、轮数及写作进度；Markdown 通过标题层级交换正文。导入先展示预览，再合并或替换。
- 快速插入可在光标处插入或覆盖输入框，独立设置是否发送。默认插入且不发送，调用原生输入/发送节点。
- 自动写作按树顺序执行有内容的叶节点，父节点作为背景，跳过完成项。可从选中节点开始，或仅执行子树。首轮发送指令，后续轮次调用原生续写，保存轮次进度后推进节点。
- 暂停等待本轮完成；停止取消当前生成和后续调度，保留已成功保存的进度。手动输入、修改大纲或生成/保存失败会暂停。刷新后恢复为暂停，需要手动继续。

默认快捷键：Alt+Shift+O 打开大纲工作区，Alt+Shift+I 插入当前节点，Alt+Shift+P 暂停/继续写作。完整编辑操作默认不绑定；在左下「快捷键」自定义。

数据库总结及语义进度匹配本轮不启用，宿主预留只读接口，后续与数据库插件接入。

## 生图

正文铅笔旁的图片按钮进入手动生图模式；RP 当前对白的编辑按钮旁也有同一入口。原输入框暂存聊天草稿，输入独立提示词后按发送/Enter 生图，完成提交后恢复原草稿。取消也会恢复草稿。该模式只拦截生图提交；正常剧情发送不变。

右栏「生图」用于查看目标楼层、场景来源、正负提示词、任务状态和图片结果；完整配置页集中管理后端及转写连接。Alt+Shift+G 打开工作区，可自定义。

- 「仅转写」使用独立模板和连接请求，不改变主聊天连接、预设或提示词。可选择当前已保存连接配置或指定连接配置。无连接配置时会提示先保存/选择配置。
- 「转写并生成」先清洗再生成；「生成」直接使用已编辑的正负提示词。场景范围可配置，排除系统消息、思考块和图片任务内容。无有效提示词时不请求生图。
- 图片保存到酒馆 `/user/images/` 后作为原生媒体附件插入正文后，保留正文。可点击插入当前目标楼层，拖入其他楼层，重新生成替换或移除附件。移除附件不删除保存的图片文件。
- 自动生图默认关闭；开启后每 x 次成功剧情回复触发，默认 3 次。正常生成与续写计入，重生成、候选切换、转写、失败/停止和媒体改动不计入。刷新后从新回复重新计数。
- 同时运行一个生图任务。目标聊天、消息对象和回复版本都需匹配；目标改变时结果留在待选区。失败保留提示词及目标供重试。
- 收纳工作区或 Noval / RP 切换不打断任务，顶部任务条提供暂停/继续/停止。切换聊天、退出原生界面或停用功能会停止当前任务。

### 五类后端

| 后端 | 地址/认证 | 说明 |
| --- | --- | --- |
| OpenAI 兼容 | `/v1` 基址或完整 `/images/generations`；用户配置密钥 | 地址和密钥均留空时使用酒馆已保存的 OpenAI 密钥及原生转发 |
| Gemini | Google 基址或完整 `:generateContent` 地址；独立 API 密钥 | 原生 Gemini 多模态结果，不混用 Imagen 接口 |
| NovelAI | 独立密钥可直连；留空使用酒馆 NovelAI 密钥 | 支持 ZIP 图片返回与酒馆 base64 返回 |
| A1111 | WebUI 地址 | `/sdapi/v1/txt2img`；取消等待不会调用全局 interrupt |
| ComfyUI | ComfyUI 地址及 Checkpoint/API 工作流 | 默认工作流或 API JSON；QIG `{prompt}`、`{negative}`、`{seed}`、`{width}`、`{height}`、`{steps}`、`{cfg}` 占位符；按任务轮询与取消，不调用全局 interrupt |

自定义后端由浏览器直接访问，需要服务允许酒馆来源的 CORS。没有新增代理服务或修改酒馆核心。超时默认 300 秒可配置。旧 ComfyUI 无定向运行任务取消接口时，仅撤销本地任务/移除排队项，服务器中已运行的计算可能继续；迟到结果不会插入聊天。

密钥仅存用户配置，不写入聊天元数据、图片结果或大纲导出。QIG 固定提交 `5915f096d899960b5013b759556098d310b2fc08` 的选定库已复用；MIT 声明保留在源码和交付目录。

## 构建、验证与交付

`npm run build` 生成主入口、记录导出、大纲、生图及共享 chunks。交付整个 `extension/`，包括 `extension/addons/` 清单，不能单独复制入口。源码、运行数据及服务配置分离，复用既有验证实例，无服务配置变更。

- `npm run typecheck`、`npm test`：数据结构、导入导出、自动写作、多轮暂停/停止、保存失败、清洗、五种模拟后端及计轮保护。
- `node scripts/verify-writing-addons.mjs`：实际酒馆浏览器回放，设置/聊天/图片写入均拦截；模型请求用模拟事件与响应，不消耗真实额度，不修改真实聊天。
- `npm run verify:addons`：记录导出按需加载、释放、失败重试和兼容性回归。
- `node scripts/verify-addon-design.mjs`：局域网静态预览、动画及多个视口检查。

浏览器截图和报告写入忽略跟踪的 `artifacts/writing-addons/`，以 1496×817 为主；真实模型与五种外部服务的认证/CORS/配额应由使用者配置后验证。
