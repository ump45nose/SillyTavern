## S2：Markdown 实时编辑器

**决定**
- 基于 CodeMirror 6（view / state / commands / language + @lezer/markdown 的 GFM 解析），打成单独的懒加载 chunk（minify 后约 318 KB，未 gzip），开启实时预览时由输入框在启动时加载。不用 lang-markdown：它会带上 HTML / CSS / JS 解析器（约 150 KB）。
- 实时预览：光标所在行显示源码，其他行隐藏标记，直接显示效果。
- 单个换行就是换行，和酒馆 showdown 的 `simpleLineBreaks` 一致。
- 输入框接入（`src/ui/md/composer.ts`）：原生 `#send_textarea` 仍是数据源和布局：
  - 编辑器盖在 textarea 的盒子上，字体、内边距、颜色从它的计算样式复制，各模式（桌面 / RP / 手机 / 生图）的 CSS 不用重写；textarea 的字用 `-webkit-text-fill-color` 隐去；
  - 编辑器 → textarea：写 `value`、同步选区，并派发 `input`；
  - textarea → 编辑器：实例上包一层 `value` / `setSelectionRange` / `select`，`input` 事件也会同步；
  - 焦点：textarea 获得焦点后（在 document 捕获阶段监听 `focusin`，因为 jQuery 的 focus trigger 会拦掉原生事件），在微任务里转给编辑器，并带上 textarea 当时的选区（Playwright 等在隔离 world 里运行的脚本看不到实例上的覆盖）；
  - 编辑器不处理的按键和文件在 textarea 上重放：普通行的 Enter（酒馆 Enter 发送、生图模式）、空草稿的方向键（滑动、编辑上一条）、粘贴 / 拖入文件；
  - 以「/」开头的草稿是斜杠命令，切回原生 textarea（带酒馆自动补全），去掉「/」后回到编辑器；
  - 点发送等按钮后焦点回到编辑器，与酒馆对 textarea 的处理一致。
- 设定类字段统一用 `<MdField>`；关闭「Markdown 实时预览」或 chunk 加载失败时渲染原 textarea。各处原有 textarea 样式改为 `:is(textarea, .wb-md)`，`.wb-md` 自身的基线样式零优先级。
- 验证脚本：`session()` 改为从运行它的检出提供扩展文件（实例链接的是主检出），worktree 里的验证测的是自己的构建；新增 `fieldValue()` 读取编辑器内容。
