## 范围与验收

1. 左边栏
   - 收起/展开动画顺滑：栏与纸面同一时长和缓动，展开时不出现滚动条。
   - 「对话楼层」高亮跟随正文中当前阅读的楼层（点击跳转或滚动都会更新），不再固定为最后一层。
2. 滚动条只在滚动时显示（工作台 UI、#chat、输入框），停止约 1 秒后隐藏。
3. 边栏收纳控件只剩箭头：无底色、无阴影，箭头放大；悬停临时展开的左栏改为不透明底并带阴影。
4. 输入框拖动调高：拖动中直接写 CSS 变量（rAF），松手才写入偏好；键盘/双击复位有高度过渡；贴底阅读时正文保持贴底。
5. 独立设置页
   - 预设 · 提示词、高级参数：去掉与「参数与预设」重复的控件，重新布局。
   - 用户设定列表头像统一尺寸。
   - 其余设置页统一页面骨架（标题行、分组卡片、字段网格）。
6. RP 桌面（RpDesktop）
   - 顶栏默认隐藏，布局切换器跟随顶栏，不常驻。
   - 玻璃配色与透明度按设计稿（亮 .86 / 暗 .74 对白框，.62/.78 卡片）。
   - 发送键为 accent 底；输入行补齐 Noval 底部工具。
   - 正文区固定高度可滚动，不与输入行重叠。
   - 分段控件：段落点 + 上一段/下一段。
   - 对话记录入口常驻。
   - 立绘约 800px 高，对白框 1080 宽、正文 19px 衬线。
