# 首版资源编辑补充设计

本次执行首版方案时补齐连接、预设、用户设定的页面结构，沿用已确认的暖纸主题与资源列表组件。属于实现方案，尚未获得单独的视觉确认。

- 右栏：顶部沿用角色 / Trace 切换，资源列表含搜索；条目主体打开详情，右箭头执行切换。连接列表按模型分组。详情展示当前配置与独立编辑入口。
- 独立编辑：左侧 260px 资源列表，右侧编辑工作区，顶部返回工作台；编辑草稿关闭前提醒。
- 连接：名称、模型、模型分组；API 类型、地址、密钥以及新建连接由原生配置面板编辑，不另建凭据表单。分组保存为插件元数据。
- 预设：右栏展示参数摘要及模型 / 连接绑定，独立页提供完整 JSON 编辑；复杂提示词排序继续使用原生编辑器。连接绑定优先于模型绑定。
- 用户设定：名称、标题与描述；头像、锁定和注入位置使用原生 Persona 编辑入口。
- 打开原生高级面板时暂时收起独立页模态状态，关闭后恢复原草稿。
- 已确认的世界书和角色布局不受此补充设计改变。

首版快捷键统一为 Alt+Shift，1/2/3/4 打开连接/预设/世界书/用户设定，N 下一个连接，L 左栏，T Trace；避免占用原生编辑和发送组合。世界书为多选资源，“下一个”只浏览，不清空已有启用项。
