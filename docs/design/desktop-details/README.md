## 确认的布局

- 延续纸张风格、暖白背景与陶土色强调色。
- 角色右栏上方固定收藏角色，下方切换“全部角色 / 当前角色”。保留原版 SillyTavern 的使用逻辑，以样式与布局调整为主。
- 全部角色提供搜索、排序、收藏及新建、导入、群组入口；当前角色保留名称、角色描述、第一条消息及高级定义等编辑字段。
- 独立角色管理页提供筛选、搜索及批量标签、导出、删除的布局预览。
- 世界书右栏并列显示世界书与条目，并提供条目摘要和独立深度编辑入口。
- 世界书深度编辑页由世界书列表、条目列表、正文编辑和参数栏组成。世界书直接在列表中选择，不再使用下拉框。
- 条目左侧激活方式控件支持关键词、常驻、向量化；绿色表示关键词、蓝色表示常驻、紫色链条表示向量化。启用勾选与激活方式分开操作。

## 预览入口与边界

默认打开角色右栏的“全部角色”。点击顶部世界书控件进入世界书右栏，再点击“深度编辑”；点击角色栏的“管理”进入独立角色管理页。
