## 布局依据

主视口为 1496×817 CSS 像素，对应用户 2992×1634 截图。页面直接根据浏览器视口布局，不缩放固定画布。继承当前工作台 74px 顶栏、260px 左栏、460px 右栏；较窄桌面沿用 240px／440px，在 1100px 以下采用覆盖式右栏。

使用现有纸色、陶土色、实心圆、淡底色与细边框。收纳控件为无底色贴边箭头。折叠、抽屉、控件按压及状态切换保留动画，并支持系统减少动画设置。

- 左栏：当前聊天大纲树、完成数量、选中节点及搜索；复用当前导航结构。
- 大纲右栏：节点内容／写作与进度，底部集中放置快速插入；完整编辑入口在表头。
- 完整大纲：紧凑顶栏、左树、Markdown 编辑及可收纳预览，底部集中插入与自动写作。
- 生图右栏：目标楼层、提示词与即时生成，图片结果／自动规则分组；长模板与场景默认收纳。
- 生图配置：后端、转写及自动规则分组。连接聚合为一行，常用参数四列，工作流与长模板跨列。
- 后台任务：输入工具栏持续展示状态及暂停／停止；完整编辑页也保留同样入口。

## 可审阅的交互

大纲支持选择、搜索、折叠、拖动排序、新建同级／子节点、复制／删除、三态进度与轮数。左栏整块收纳会释放区域高度；章节逐级展开使用高度过渡。点击叶节点左侧箭头展开内容摘要、状态与轮数，并可直接插入或转到右栏编辑。默认展示一个展开节点，便于对照收纳效果。Alt + 方向键排序和调整层级；Shift + 拖动移入节点。Markdown 渲染转义原始 HTML。

导入先分析，再选择合并或替换。JSON 导出保留结构、状态和轮数；Markdown 使用标题层级。自定义快捷键提供冲突反馈。快速插入演示光标处插入／覆盖，以及是否发送。

自动写作使用计时器演示：有内容的叶节点执行、父节点提供上下文、首次指令与后续续写、多轮推进、等待本轮结束后暂停、立即停止、手动介入暂停，以及收起右栏后继续。

生图以已有 RP 场景图片模拟结果，演示仅转写、直接生成、转写并生成、错误重试、后台取消、图片插入／替换／移除与拖入指定示例楼层。自动规则支持计轮及两种结果交付。

五类后端展示对应配置布局。配置编辑仅保留在当前页面内存中；刷新还原示例。凭据控件禁用，不采集密钥。所有请求仅用于载入本地静态资源；CSP 禁止网络 API 请求。

数据库总结与辅助匹配进度仍为后续范围，预览不增加空入口。
