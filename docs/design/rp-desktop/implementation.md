## 尺寸与设计对照

以 1496×817 CSS 像素为主复查尺寸，参考用户截图的 2992×1634 比例，同时检查 2992×1634 CSS 窗口。

顶栏高 74px。对白宽度默认占剩余舞台的 88%，离底边 3vh（20–40px）；正文／输入主体高 25vh（180–360px），展开输入高 48vh（260–620px）。这些尺寸随实际内容窗口变化，不再用固定画布缩放模拟网页。

1496×817、两栏收起时，原生主体实测为 x=89.75、y=588.25、宽 1316.47、高 204.25；上方对白表头与说明合计 80px。确认稿相应主体约 x=89.77、y=587.25、宽 1316.47、高 204.25，差异来自实际边框约 1px。

真实背景复查后为对白工具补齐纸色底面和细边框；分页控件合并为一组，保持深色背景上的可读性。辅助卡与画像不在窄舞台上叠放，输入展开时收起建议与场景信息。

## 数据与兼容

不会复制或重建原生消息、输入、媒体和助手 iframe。对白分页只对现有 HTML 块施加显示类；代码、表格、图片和 iframe 保持完整。超过视口的单段保留原文并可滚动，「继续」先向下阅读，再进入下一段，避免截断 Markdown 或插件输出。普通输入法、原生发送快捷键与文本编辑保留原路径。

设计稿的示例人物、天气、地点和示例回复不写入真实聊天。舞台使用当前角色／身份和表情扩展资源；没有专门场景数据时显示角色名称与消息时间。可选场景元数据来自 `chatMetadata.workbenchRP.scene` 的 `day`、`location`、`weather`、`time`，本轮没有新增场景数据编辑器或模型推断。

建议回应来自已启用快速回复，最多显示三项，点击填入原输入框。实际执行快速回复及 STscript 继续使用原有输入底栏入口。
