## 当前布局

舞台和对白保留 RP 的 Galgame 布局；顶栏、导航、资源边栏沿用当前工作台的纸色底面、圆角、细边框与陶土色强调。角色头像改为圆形面部缩略图与单行名称，移除原来的矩形角色卡与副标题。

- 两个边栏每次打开预览时默认收起。左侧沿用聊天管理、当前对话、历史、大纲、楼层与底部设置入口；历史和大纲默认折叠。
- 右侧沿用紧凑模块表头。连接、预设、世界书、用户设定的一级资源列表在编辑栏左侧外展 180px，包含搜索、实心圆选中标记和收纳控件；收起后可在编辑栏表头重新展开。
- 顶栏可通过图钉控件或外观面板中的“自动收纳顶栏”设置收起。鼠标进入顶部边缘时显示，离开后收起；打开配置选择框或键盘焦点留在顶栏时保持显示。悬浮显示覆盖舞台，不改变对白位置。
- 眼睛图标固定在右上角的同一按钮内。隐藏与恢复界面只切换图标和状态，不移动按钮；与边栏按钮预留独立点击区域。临时隐藏界面会保留原来的边栏状态、草稿和页码。
- 双立绘保留发言者高亮。日期、时间、天气与地点信息框采用统一的纸色与细边框。
- 下方对白支持左右翻段，最后一段后进入输入页；翻回对白保留草稿。输入底栏保留纯图标、工具提示和可访问名称。
- 三个建议回应位于输入页外，锚定对白区域上方；展开输入时同时收起建议回应和场景信息卡，避免与输入区叠放。左右两栏同时展开时，阅读工具也改为图标，避免挤压舞台。
- 侧栏进出、顶栏显隐、输入展开、翻段、折叠内容、弹出菜单与控件状态保留动画，并响应系统的减少动画偏好。

## 屏幕比例

参考用户提供的 2992×1634 内容截图，宽高比约 1.831。预览铺满浏览器内容区，取消外层留白、按宽度生成高度及 900px 高度上限。

截图像素不能单独确定浏览器的 CSS 尺寸或设备像素比；主画面复查使用 1496×817 CSS 像素、输出 2992×1634 图像，同时覆盖 2992×1634 CSS 像素窗口。

- 桌面顶栏高 74px，四个快捷资源居中，合计最大宽度 860px。
- 左边栏宽 260px、右编辑栏宽 460px；1400px 及以下桌面窗口分别为 240px、440px。
- 对白区占剩余舞台宽度的 88%；对白和展开输入的高度随窗口高度调整，立绘同时受可用舞台的宽度与高度限制。
- 1100px 及以下采用覆盖侧栏，左、右边栏互斥；打开时收起对白，关闭后恢复草稿与页码。较窄手机窗口的资源列表缩为 144px。
