# 功能与控件清单 · v2 设计输入

日期：2026-10-11 · 基于 0.4.0 源码（`src/`）整理。这份清单是 v2 设计稿和保存语义定稿的依据，不是设计方案本身。

## 0. 记法

**频率**
- **常驻**：每次会话都在用。
- **高频**：每次会话用到几次。
- **中频**：每天或每个故事用到几次。
- **低频**：配置期才用。

**目标层级**
- **L0 常驻**：始终可见。
- **L1 快切**：顶栏浮层或快捷键。
- **L2 边栏轻编辑**：右栏加 180px 资源列。
- **L3 全量编辑**：独立工作区。
- **L4 设置**：设置工作区。

**保存类别**（D3）
- **A 即时**：选择、启用、绑定、偏好。
- **B 原生即时设置**：防抖写盘，标题栏显示保存状态标记。
- **C 草稿**：内容编辑，有修改时出现保存条，保留冲突检测。
- **P 预设模型**：沿用原版。修改直接作用于当前运行的参数，再用「更新预设」写回文件，「还原」回到文件里的内容。

**场景列**：N = Novel，R = RP；D = 桌面，M = PWA。✓ 表示该场景有此功能。

> **已确认（2026-10-11）：采用 P 模型。** 原版酒馆的采样参数和提示词开关是即时作用于当前运行的，「更新预设」才写回文件。插件现在把它们放进草稿，连「流式传输」这种高频开关都要先保存才生效。改为 **P 模型**：参数与开关即时生效；只要和文件内容不同，就出现「预设有未写入的修改 · 还原 · 更新预设」。提示词正文编辑仍然走 C，保存后作用于当前运行的参数，计入预设未写入的修改。

## 11. 0.4.0 回归基线（本机实例）

修正分三类，均未改产品代码：

| 类别 | 脚本 | 内容 |
| --- | --- | --- |
| 计数过时 | home、interactions、preferences | 三个内置附加插件默认开启：右栏页签 6→9、输入区工具 5→6、快捷键 9→14 |
