## C7：保存语义与命名

- **术语表** `src/host/labels.ts`：资源、面板、设置页、动作的名称都从这里取。按确认的四项改名：生成配置 → 预设，连接记录 → 连接配置，重生成 → 重新生成（含「自动重新生成」），代入 → AI 帮答（此前已改）。
- **预设采用 P 模型**：编辑的是当前运行的预设（Chat Completion）时，参数、开关、提示词启用与顺序、新增和删除提示词都通过酒馆自己的控件即时生效；提示词正文和提示格式仍是草稿，保存后作用于当前运行的参数。运行状态与预设文件不同时出现「预设有未写入的修改 · 还原 · 更新预设」。「更新预设」保留文件里酒馆不认识的字段。编辑的不是当前运行的预设时，仍按文件草稿处理，保存按钮叫「更新预设」。
- **统一保存条** `SaveBar`：预设、连接配置（按钮「更新连接配置」）、用户设定、世界书、角色、群组、群聊覆盖共用。只在有修改时出现，保存后短暂显示「已保存」；`⌘S` / `Ctrl+S` 在所属编辑区内保存。
- **设置页**：去掉「保存设置」按钮，标题栏改为状态标记「设置已保存 / 设置保存中 / 设置保存失败 · 重试」。资源编辑区（`fieldset`）的输入不计入。
- **删除的说明文案**：「设置即时生效 · 资源草稿单独保存」「常规设置即时生效 · 资源修改请保存」「设置即时生效」「当前运行连接 · 设置由酒馆即时保存」中的保存说明，以及两处「保存后生效」。Trace 的采集口径说明改为 ⓘ 提示，文字不变。
- **计算样式**：30 个状态都有差异，全部来自上述改动（导航文字变短、空闲时不再显示保存条、标题栏按钮移除）。此后 `verify:styles` 默认以 `artifacts/baseline-c7/computed` 为基线；需要与 0.4 比对时设置 `WB_STYLE_BASELINE=artifacts/baseline-0.4/computed`。

## C6：边缘通道

- **几何分离**：新 token `--wb-edge-lane: 36px`。开启「边缘悬停展开侧栏」时，侧栏收起的一侧，`#sheld` 向内让出一条通道，`#chat` 的滚动条永远不在通道里；边缘箭头宽度取同一个 token，只放在通道内。侧栏固定展开的一侧不需要悬停展开，所以不留通道，阅读宽度与之前相同。
- **意图过滤**：按住按键（拖动滚动条、选择文字）、500 ms 内有滚轮滚动、停留不足 180 ms，都不展开。按键状态从每次 `pointermove` 的 `buttons` 读取，因为按在原生滚动条上时，`pointerup` 可能不会到达页面。
- **通道宽度从 28px 改为 36px**：箭头原本就是 36px，28px 的通道会让箭头压到滚动条上。
- **拖动后误点箭头**：Chromium 在滚动条拖动结束、松开位置恰好在按钮上时，会对这个按钮派发一次 click。原先这次 click 会把右栏固定打开。现在边缘箭头只响应「在箭头上按下」或键盘触发的点击。
- **设置**：用户设置里新增「边缘悬停展开侧栏」，默认开启；关闭后通道和悬停展开一起去掉，箭头仍可点击。
- **计算样式**：与 `baseline-c7` 相比，差异只在右栏收起的桌面态：`#sheld` 的宽度和边距，以及随之重排的消息；另有设置页新增的开关。固定侧栏的状态与 PWA 无差异。此后 `verify:styles` 默认以 `artifacts/baseline-c6/computed` 为基线。
- **验证**：`npm run verify:edge` 覆盖几何、拖动越过通道、滚轮后移入、快速经过、开关、固定侧栏时无通道、在箭头上松开拖动。
