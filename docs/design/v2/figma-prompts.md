# Figma 设计提示词 · Noval 工作台 v2

日期：2026-10-11。依据 `inventory.md`（功能清单）、`architecture.md`（C 阶段结果）和 `src/styles/tokens.css`（现行 token）整理。

## 用法

1. 每开一个 Figma 文件或对话，**先粘贴「0. 全局上下文」和「1. 设计系统」**，再一次粘贴一个页面提示词。
2. 页面提示词彼此独立，可以按任意顺序生成。建议的顺序是：2.1 → 2.2 → 2.3 → 2.4（四个主页），然后按第 3 节的顺序生成独立页面。
3. 每个页面都要求出亮色版和暗色版。两种都出完之后，再用「4. 追加提示词」检查长文本、空状态和错误状态。
4. 画板尺寸：
   - 桌面主尺寸 **1496×817**；
   - 校验尺寸 1366×768 和 1920×1080；
   - PWA **390×844**（iPhone 14 尺寸）。
5. 界面文案一律使用下文给出的中文原文。四个改名已经定稿：预设、连接配置、重新生成、AI 帮答，不要换成别的说法。

## 0. 全局上下文（每次先粘贴）

```
你在为「Noval · 工作台」设计界面。它是 SillyTavern（酒馆，一个 AI 角色扮演与小说创作的本地网页应用）的一个界面扩展，完全替换原版的界面外壳，但底层仍然是酒馆的聊天、角色、预设、世界书等数据。

产品有两种模式，每种都有桌面和手机 PWA 两个版本，共四个主页：
- Novel（小说创作模式）：以长文本阅读和写作为中心。阅读区像一本排版精良的书：衬线正文、舒适行距、居中的阅读栏，AI 消息不做气泡。
- RP（角色扮演模式）：以沉浸感为中心，视觉上像视觉小说（Galgame）。全屏背景加角色立绘，底部是半透明对白框，带名牌和分段翻页，界面元素尽量退到幕后。

目标用户是长期使用酒馆的中文创作者，一次会话持续数小时。他们需要频繁切换四种「资源」：
- 连接：API 与模型；
- 预设：采样参数与提示词；
- 世界书：设定知识库；
- 用户设定：用户扮演的身份。
除此之外还会用到角色管理，以及三个附加功能：大纲、生图、记录导出。

设计原则：
1. 美观第一，其次才是信息密度。气质是「安静的纸面工作台」：暖白纸张、墨色文字、一种陶土橙强调色。不要科技感渐变，不要霓虹，不要玻璃拟态（RP 对白框的半透明除外）。
2. 层级靠面层（surface 0–3）和阴影表达，少用描边。分隔线只用于列表行之间的极细线。
3. 一屏只有一个主操作使用强调色实心按钮，其余按钮用幽灵按钮或弱化样式。
4. 字号：界面文字最小 13px（只用于说明和计数），默认 14px；阅读正文 17px，行高 1.9。触屏控件不小于 44×44。
5. 四种资源都有「快切」和「完整编辑」两个入口，这是有意设计，两个都要保留；但快切入口要轻，不能抢阅读区的注意力。
6. 不写任何解释性的文案（例如「设置即时生效」「保存后生效」）。状态用控件本身表达。
7. 保存语义只有四类，视觉必须一致：
   - A 即时：选择、启用、绑定、排序。点了就生效，不出现保存按钮。
   - B 设置页：没有保存按钮。设置工作区标题栏右侧有一个状态标记，在「设置已保存 / 设置保存中 / 设置保存失败 · 重试」之间切换。
   - C 内容草稿：编辑区底部的保存条，只在有修改时出现，内容为「未保存的修改 · 还原 · 保存（⌘S）」。保存后短暂显示「已保存」。
   - P 预设：参数即时作用于当前运行；与预设文件不同时，出现提示条「预设有未写入的修改 · 还原 · 更新预设」。
8. 所有内容使用真实感的中文示例：小说段落、角色名、世界书条目、模型名。不要使用 Lorem ipsum。

示例数据（各页面统一使用）：
- 角色「林间」：雾港旧书店的店主，沉静，有秘密。另有角色「Seraphina」和「白砚」。
- 当前对话「雾港来信」，共 128 层。
- 连接配置「Claude 主力」（服务商 Anthropic，模型 claude-sonnet），以及「本地 Qwen」「OpenRouter 备用」。
- 预设「长篇叙事 v3」（流式传输开、温度 0.9、上下文 64k）。
- 世界书「雾港设定集」，已启用 2 本，显示为「雾港设定集 +1」。
- 用户设定「旅人」。
- 小说示例段落：
  「雨停在黄昏之前。沿河的旧书店亮起一盏灯，暖光落在窗边那封没有署名的信上。林间把书页折回原处，抬头看向门口。“你终于来了。”远处传来一声雾笛。」
```

## 1. 设计系统（每次先粘贴，紧跟全局上下文）

```
请先建立设计系统：在 Figma 里创建对应的 Variables（亮色 / 暗色两个 mode）和组件，后面所有页面都只使用这些 token。

颜色（亮色 / 暗色）：
- surface-0 应用背景：#FAF9F5 / #1C1A17
- surface-1 卡片与面板：#FFFEFA / #24211D
- surface-2 柔和底色、输入框底：#F0EEE6 / #2C2924
- surface-3 选中行：#F3EADF / #3A2E26
- ink-1 正文：#302E29 / #ECE7DD
- ink-2 控件文字：#6C6254 / #C3B9A8
- ink-3 次要文字：#817A6C / #968D7F
- line-1 细分隔线：#DFDCD2 / #3A362F
- accent 强调（陶土橙）：#B76449 / #D9876A；accent 上的文字：#FFFEFA / #1C1A17
- selected 选中底：#F0E6DA / #3A2D25
- success #719783，warning #C99A3E，danger #C4553A，info #6F8FB0（暗色下各提亮约 10%）

字体：
- 界面字体：苹方 / Noto Sans SC（系统无衬线）。
- 阅读字体：思源宋体 / Noto Serif SC。
- 等宽字体：SF Mono。

字号阶梯：
- 12 只用于计数和角标；
- 13 说明；
- 14 默认；
- 16 小标题；
- 19 页面标题；
- 24 大标题；
- 阅读正文 17。

字重 400 / 500 / 600。行高：界面 1.45，阅读 1.9。

间距：4px 网格（2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40）。

圆角：4 / 6 / 8 / 12 / 16，另有胶囊形。按钮和输入框用 8，卡片和面板用 12，浮层用 12，对话框用 16。

阴影（层级 1–3）：
- 1：0 1 2 rgba(52,41,30,.05)
- 2：0 4 18 rgba(52,41,30,.08)
- 3：0 12 40 rgba(52,41,30,.14)
暗色下用更深的阴影，并给面层加 1px 内高光。

控件高度：小 28，中 34，大 40，触屏 44。

布局几何（桌面）：
- 顶栏高 64；
- 左栏宽 260；
- 右栏宽 460，右栏内的资源列宽 180；
- 屏幕两侧各有一条 36px 的「边缘通道」，放置侧栏开合箭头；
- 阅读栏最大宽度 46em。

需要的组件（每个都要有 默认 / 悬停 / 按下 / 聚焦 / 禁用 / 选中 状态）：
- 按钮：主按钮（accent 实心）、次按钮（surface-2 底）、幽灵按钮、纯图标按钮（34 和 44 两种尺寸）、危险按钮
- 资源胶囊（ResourcePill）：图标 + 当前值 + 下拉箭头 + 悬停才出现的「下一个」箭头；连接胶囊左侧有状态点（已连接为绿色、连接中为琥珀色、未连接为灰色）；世界书胶囊显示「+N」
- 分段控件、页签（下划线式）、开关、勾选框、单选、滑块（带数值输入）、下拉选择、搜索框、文本框、多行文本框（可拖动高度）
- 列表行：可勾选、可选中、带次要信息、带拖动手柄
- 折叠分组（标题 + 计数 + 展开箭头）
- 浮层（Popover）、对话框、右侧抽屉、底部动作表（PWA）、Toast
- 保存条 SaveBar（C 类）、预设未写入提示条（P 类）、设置保存状态标记（B 类）
- 空状态（插画用线描小图标即可，配一句话和一个操作）、错误条（danger 细条加重试）
- 消息块：Novel 的 AI 段落（无气泡）、用户段落（surface-2 底、左缩进）、楼层元信息行（悬停出现）
- RP 对白框、名牌、页点、建议回复胶囊
```

### 2.1 Novel · 桌面主页

```
画板 1496×817，再出一个 1366×768 版本。分别出亮色和暗色。

整体是三栏，中间的阅读栏是主角：
左栏 260（可收起） | 阅读区（自适应宽度，正文栏最大 46em 并居中） | 右栏 460（默认收起）

  - 标题旁有一个铅笔图标，用于重命名。

## 3. 独立页面

### 3.1 资源快切浮层（L1，四种资源）

```
在 Novel 桌面主页上，从顶栏资源胶囊向下弹出浮层（宽 320，surface-1，圆角 12，阴影 3）。四个浮层分别出图：

- 连接：
  - 列表按「模型分组」分组显示，分组标题为小号 ink-3，例如「主力」「本地」「备用」；
  - 每行显示状态点、连接配置名和模型名，单选，当前项打勾；
  - 底部有「打开详情」和「查看全部与编辑」。
- 预设：单选列表，当前项打勾；底部同上。
- 世界书：多选勾选；顶部显示「已启用 2 本」；底部同上。
- 用户设定：每行带头像的单选列表；底部同上。
