# 资源右栏再次修订 · 已确认并接入

2026-10-07。按用户最新截图与反馈修订，保留此前确认稿作为历史。三个右栏的布局已获用户确认，本次按最新“模型与连接／测试前置、统一滚动条、去除双层悬浮底色”的反馈更新预览并接入实际页面。

## 已接入验证实例的细节

- 工作台拥有的下拉框改为纸张列表，使用空心／实心圆标识选中；支持方向键、Home／End、Enter、Escape，以及滚动边缘定位。保留原选择事件；独立编辑页面的菜单在原对话框内展示。
- 搜索框在外层显示唯一焦点反馈，不再给内层输入叠加错位的边框。其他输入统一采用轻边框和淡色焦点反馈。
- 顶部详情图标和连接状态点悬浮时不绘制矩形块；角色页签采用文字与底线反馈，收藏头像只强调圆形轮廓。头像轮廓占位固定，选中不改变位置或尺寸。
- 世界书下半区始终是编辑器，选中条目后直接编辑正文和触发条件，删除“编辑条目”与“收起编辑”入口。
- 输入工具、发送和窄宽度排列保持现有已确认结构；本次没有提前改造菜单、扩展工具或快捷回复流程。

## 已接入的三个新右栏

预览源：[resources-redesign.fragment.html](resources-redesign.fragment.html)。独立预览：[resources-redesign.html](resources-redesign.html)。仅展示需要重做的三种右栏内容，正式页面继续保留六类右栏导航。

- **连接**：标题点击弹出配置选择；新建、记录、删除三个按钮移到表头。API 配置最前面依次是模型、连接／测试，其后才是接口类型与服务商。下方接入完整原生 API 表单，保留地址、凭据管理、代理、服务商专属选项和原生事件；重复的原生配置工具条仅在工作台容器内隐藏。连接记录与绑定收纳，包含分组、绑定、记录字段和应用范围。模型及服务商快捷控件只映射非敏感字段，凭据继续由原生控件持有。
- **预设**：标题点击弹出预设选择，取消左侧预设列表；流式传输／请求思维链常驻，数值参数采用小尺寸行内输入，常用项通过图标配置。主体为满宽、独立滚动、可启停的提示词列表，下方直接编辑名称、角色及原文，提供排序。其他参数、格式、绑定、文件管理收纳为“更多预设设置”。
- **用户设定**：圆形头像及身份选择位于表头，名称／说明标题与描述优先显示；注入位置、深度、角色、世界书绑定直接展示；默认身份、角色／聊天锁定及全局偏好集中排列。头像、更换、新建、复制、名称同步、统计、备份恢复和删除保留清晰入口。

三页统一暖纸表面、陶土强调、轻边框、空心／实心圆和 160ms 控件过渡。预览按 460px 右栏宽度与 826px 可用高度展示，并检查小容器防溢出。预览操作只改变本地样例，不连接 API、不提交凭据、不写入酒馆；其中保存、连接测试与管理反馈明确带“预览”标识。

三个布局已替换真实右栏，已有保存、冲突检查和未知字段保留逻辑继续复用。原生 API 表单使用同一个 DOM 节点挂载；退出面板时恢复位置并移除工作台标记。连接表头通过官方配置管理器新建、记录、删除，新建后选中新的记录；Persona 新建／复制事件同步更新列表。独立编辑页继续使用同一组业务组件，预设深度编辑使用列表与编辑区左右展开。

连接的记录／删除针对已应用的连接，新建直接捕获当前 API 设置；浏览其他记录不会隐式切换 API。较低屏幕下压缩提示词编辑区，保留列表作为主体；原生 API 面板在嵌入时取消固定最小宽度，避免输入框被裁切。

滚动条在阅读区、资源列表、编辑区和弹出菜单统一为 6px 暖灰圆角，轨道透明；Firefox 使用 thin 对应样式。资源行只有整行轻色反馈，嵌套按钮悬浮保持透明，选中行不会再次叠加白色块。标题、圆形状态、输入焦点、列表、菜单和折叠沿用统一过渡；减少动态效果偏好继续生效。
