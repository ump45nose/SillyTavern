## 实现范围

聊天管理替换左栏原先的大纲／最近对话区域并置顶。新对话和聊天文件两个按钮常驻；当前对话展开并用暖色标注，支持重命名。历史对话默认收纳并按最近时间排序；重命名、导入、删除后自动同步。大纲默认折叠且明确占位；最近五层可展开。信息区约占左栏三分之二，下方完整保留九类设置。

输入底栏的菜单、扩展工具、续写、重生成、快速回复、AI 帮答、附件均为纯图标，保留提示与无障碍名称。AI 帮答位于快速回复右侧。菜单、扩展工具、快速回复、聊天操作和文件管理共用纸张弹出容器，依触发位置翻转并限制在视口内。快速回复按原集合分组，运行安装的官方 API；编辑后使用插入原始文本。作者注释与 CFG 在同一容器内操作原生表单，其他扩展动作调用原入口。聊天操作菜单提供群聊转换、删除消息、关闭聊天和群组管理，文件面板提供打开、导入、导出、重命名和确认删除。

阅读区保留原 `.mes`、正文、图片、附件及 iframe 节点，增加呈现类与独立的小控件。头像和名称隐藏；时间与楼层默认悬浮／聚焦显示，可配置始终显示或隐藏。用户消息默认收成摘要，展开仅改变当前消息状态；编辑时强制展开，保留原生编辑节点与处理事件。正文右侧提供字体、14–24px 字号、1.5–2.4 行距和默认折叠设置。消息操作及编辑确认／复制／删除／排序／取消使用统一细线图标与轻量控件。字体使用设备的宋体／黑体系列，缺失字体时由浏览器回退；不从外部字体服务加载资源。消息保存继续执行官方既有宏替换语义，工作台不额外进行富文本转换。

九类独立设置统一占用整个工作区，保留原生配置、插件事件及保存能力。复杂表单按完整原生块分组和重新排版，未改为少量字段或 JSON 替代页。原生即时保存与资源草稿保存明确分开；挂载时记录节点位置，离开后恢复同一节点、顺序、下拉控件及监听。

| 类别 | 工作区位置 |
| --- | --- |
| 生成配置 | 预设集合／提示词／参数；另一组保留适用后端完整原生生成配置 |
| 连接 | 全部连接记录＋已确认的 API 编辑器；模型、连接、测试前置，表头新建／记录／删除 |
| 回复格式 | 上下文、指令模板、系统提示词、停止与分词、推理格式、其他 |
| 世界书 | 世界书管理、条目、正文、参数四区；另一组保留完整绑定和全局设置 |
| 用户设置 | 外观与阅读、消息与输入、角色／群聊、声音、脚本补全、账户、其他 |
| 背景 | 全局和聊天背景的原生管理块 |
| 扩展 | 已安装、动态扩展设置、快捷回复、正则、Extras |
| 用户设定 | 已确认的完整 Persona 编辑器，保留身份选择位置 |
| 角色管理 | 已确认的角色搜索／筛选／批量管理；群组保留完整原生管理块 |

预设、连接、世界书管理整个集合。圆形多选与正在编辑的资源独立；支持全选、部分选中、复制、导出、确认删除和取消选择，选择状态跨分类保留。多资源导出为包含各资源原生 JSON 的 ZIP，压缩工具按需加载。未知扩展字段保持原样，连接复制采用官方 UUID 方法以兼容局域网 HTTP，不复制密钥到插件配置；外部编辑器目前是明确禁用的预留控件。

草稿按模块和资源存在内存，切换资源／分类时保留；离开工作区时保存、放弃或取消。保存失败及无法解析的高级 JSON 保留原文。批量操作过程中禁用冲突操作；部分失败逐项反馈，仅失败资源保持选中。复制预设后恢复原先预设和 API／模型。回退仍恢复原消息与输入，保留原插件处理链路。
