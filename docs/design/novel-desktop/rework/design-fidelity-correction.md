## 本次代码修正

用户输入不再在显示/隐藏内容后动画整个消息高度；改为裁切原内容的最大高度及透明度过渡。消息、附件和 iframe 节点保持同一对象。左栏恢复确认稿 `#dcc9b6` 边线及打开时整行选中底色。

独立表单由工作台组件呈现。原生源容器保留在不可见的隔离位置以维持事件与同步；字段控件转发真实 input/change/click 事件，完整自定义颜色控件保留原实例。源容器离开页面后恢复原位置。隐藏原生图标后面的启用控件改用圆形勾选呈现，保留原监听器；推理字段完整归入推理格式。酒馆助手按真实设置块识别，分组动作调用原节点，并保留选中反馈。密码不会读入 React 草稿或属性；仅将用户新输入传回原控件。

角色管理使用小头像、紧凑卡片、搜索／排序／收藏／当前／标签筛选及批量操作。角色编辑增加头像、复制、备选开场、创作者信息、世界书和深度提示词。群组使用独立成员列表，补齐四种发言方式、三种角色卡合并模式、头像及成员拼图、静音立绘、外部媒体、当前群聊自动发言及情景／示例／系统提示词覆盖。配置和对话覆盖保存失败保留草稿；覆盖保存使用原有聊天存储端点并保留完整消息及未知元数据。用户设定改为身份列表＋双列表单；名称与注入位置并排，全局偏好单独成组。

世界书绑定改为独立表单，分别设置全局、角色主书／附加书和聊天绑定；扫描、预算、递归及匹配设置仍由官方运行时持有。生成配置保留参数与预设、提示词、高级参数分组。背景使用实际缩略图与原文件操作。扩展使用已安装列表、动态设置选择、快捷回复／正则及 Extras 分组。

模块内的原生回退入口已移除；主页整体退出工作台仍保留，用于兼容回退。预设／连接／世界书的集合多选、复制、导出、删除和外部编辑器占位继续保留。连接栏移除重复档案列表与操作，模型、连接／测试仍位于最前；地址与凭据明确标注并与模型对齐，其他请求参数收纳。群组长名称使用省略显示，图标保留固定尺寸。
