# 横屏 Noval · 正式主页重做记录

2026-10-07。本次用户已确认 `home.fragment.html`，正式主页依据这一版本实施。范围是开发顺序中的第一块「主页视觉与交互」；资源编辑、Trace 新版和九类独立设置工作区仍分模块接入。

## 本次实现

- 顶部使用左右等宽留位，使四组配置始终居中。详情图标、选择菜单、下一个为三个独立操作区域；连接以状态点作为详情入口。展开箭头旋转，当前资源高亮，值变化淡入。
- 暖白正文、浅米灰边栏、陶土强调；同步更新配套主题变量。图标深暖灰，隔离原生浅色前景；原生消息操作取消模糊投影。
- 左右栏默认 260/460px，较窄屏幕为 240/440px；正文和输入采用 32px 内距。右栏默认关闭。展开后空间不足会临时隐藏左栏，关闭后恢复用户偏好。
- 正文工具栏展示真实聊天名，两端为有方向的面板收纳图标。专注隐藏顶部和侧栏，退出恢复原状态；新增 Alt+Shift+F。
- 大纲保留占位。楼层默认最近五条，可展开全部；最近对话默认折叠。底部补齐九类设置入口。
- 输入仍是原生 textarea，原文、宏、XML 和宿主处理链路不变。顶部横线拖动增高，支持方向键、Home/End、双击复位；保存高度偏好。移除旧全屏输入。
- 原生菜单、扩展工具、续写、重生成、快速回复和附件在同一底栏，发送为圆形向上箭头。窄输入区隐藏操作文字但保留图标和名称。原生快速回复条收纳为二级入口。
- 右栏统一六类切换导航。角色列表改圆形头像。世界书条目合并为单个大圆，颜色表示激活方式，实心/空心表示启用状态；激活方式从名称下方选择，保存数据仍互相独立。
- 悬停、按下、菜单、选中行、圆形勾选、侧栏、折叠和专注均有过渡；输入拖动实时响应，减少动态效果偏好关闭动效。

主页拆分为 `src/ui/Header.tsx`、`Navigation.tsx`、`Composer.tsx`；`src/home.css` 承担场景样式。官方聊天与输入节点没有移动或重建。原生回退时清理新增 DOM、监听、布局属性，并恢复输入提示文本。

## 右栏接入与顶部控件 · 2026-10-07

- 顶部顺序改为 Trace、专注，均使用 24px 图标、44px 点击区域。专注去掉可见文字；开启 Trace 或专注后显示陶土色与浅色底。专注中的退出按钮同样使用图标与启用态，保留无障碍名称和悬浮提示。
- 预设右栏改为常用参数、满宽提示词列表、正文编辑及折叠的其他参数；预设选择移到标题弹出框。支持启停、排序、新增/删除提示词、注入与触发设置、提示格式、常用项配置、连接/模型绑定、预设新建/另存/删除及 JSON 导入导出。非法结构不会覆盖草稿；删除失败恢复宿主列表。高级 JSON 是辅助视图。
- 用户设定右栏直接展示头像、名称、描述、注入位置/深度/角色、世界书、默认/角色/聊天锁定与全局偏好，并提供原生头像更换、新建/复制/删除、消息名称同步、统计及备份恢复操作。当前身份保存注入字段后同步运行时。
- 连接按模型分组，标题弹出选择，表头新建／记录／删除。API 模型、连接／测试在表单最前，完整原生表单直接接入，保留各服务商专属选项和凭据管理；不会把密钥复制进插件设置。配置记录与绑定收纳，支持名称、模型、服务类型、地址、预设、凭据引用、代理、模板和排除字段。配置记录显式保存，运行 API 仍按酒馆原有即时保存逻辑操作。
- 世界书默认双列表，下半区始终直接编辑条目正文与触发条件；保留合并后的彩色启用圆圈和深度编辑入口。角色列表继续使用圆形头像，当前标记移到行右侧。

新增 `npm run verify:resources`，验证顶部控件、提示词保存与未知字段、常用参数配置、身份注入、连接节点恢复、实际 Trace 以及三种桌面宽度。截图与结果位于 `artifacts/resource-sidebars/`。单元测试增至 14 项；原有主页 9 组、工作台 11 项、兼容 10 项检查通过。功能检查与用户对真实页面的视觉确认仍分别记录。
