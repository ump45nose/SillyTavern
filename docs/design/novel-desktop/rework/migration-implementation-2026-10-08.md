## 动效、展开位置与页面密度修复

本次反馈暴露了此前验证的遗漏：验证账号的原生 `reduced_motion` 已保存为 `true`，导致整个工作台的 CSS 动画、过渡和原生 jQuery 动画停用。原版 `switchReducedMotion()` 会在读取系统减少动画偏好时强制开启此设置；验证中的媒体模拟和设置切换未完整恢复原生偏好。责任在验证流程，不能归因于用户。此次已通过原生设置事件恢复隔离验证账号的正常动画，并新增 `withReducedMotion()`，临时模拟期间保护保存请求，结束或失败都恢复原偏好。页面本身继续尊重用户和系统的减少动画设置，不强制覆盖用户偏好。

输入展开还有独立的代码问题：旧的展开状态样式保留 `padding-top:27px !important`，而折叠状态为 10px；旧折叠隐藏规则也与新高度动画冲突。现已移除这些旧规则，两种状态使用同一内距和文本起点；高度、上边距和透明度在 260ms 内连续过渡，反向点击从当前帧继续。相同状态下的消息扫描不再取消在途动画。时间／楼层和输入标题共用固定的垂直基线；悬浮信息出现时摘要渐隐，避免文字覆盖。原消息、媒体和 iframe 节点保持原生所有权。

页面顶部由 68px 主表头、48px 分组导航收紧为 58px、40px。原组件页去掉与分组导航重复的大标题和说明，保留资源自己的表头、启用开关和局部操作。角色管理、用户设定等定制管理页保留紧凑标题。背景的填充方式、自动选择、新建文件夹、上传、搜索、排序、全局／聊天切换、批量与缩放控件在四种桌面尺寸下合为同一行；窄内容区域采用两行，保留搜索可用宽度。调整只使用 CSS 网格，原生标签节点、jQuery Tabs 和文件输入均留在原所有者内。

选中边界统一为 1px 陶土色细线，配合原浅米色底。当前对话、展开的收纳控件、当前楼层、资源列表、角色／用户设定与编辑条目使用一致的边界；使用原尺寸边框或内描边，切换不改变几何尺寸。普通控件反馈为 160–180ms，收纳面板为 220ms，阅读展开为 260ms。
