## 局部交互

主页顶栏、资源右栏、左右宽度及专注／Trace 位置沿用已通过版本。第一份预览仅包含本轮变化的中央阅读区、输入工具和左栏聊天管理片段，不替换整个主页，也不移除大纲、最近五层与九类设置入口。

三个弹出框共用纸张表面、细米色边线、单层浅阴影与同一排版。宽约 294px，距离触发控件 8px；默认向上弹出，空间不足时翻转，并限制在工作区内。一次只打开一个；Esc、点击外部或再次点击触发控件关闭，Esc 将焦点还给触发按钮。弹出框使用非模态容器，不冻结输入，也不创建新窗口。选中只改变整行一层背景，内部文字按钮透明，不叠加第二层白底。

| 入口 | 新位置与设计 | 原生来源／接入要求 |
|---|---|---|
| 聊天菜单 | 输入工具最左，三条杠；作者注释、CFG、Token 概率、检查点、返回父对话 | `#options`，分别对接 `#option_toggle_AN`、`#option_toggle_CFG`、`#option_toggle_logprobs`、`#option_new_bookmark`、`#option_back_to_main`；保留适用条件 |
| 扩展工具 | 紧邻菜单，细线魔法棒；行内图标、名称，设置入口在表头 | `#extensionsMenu`；动态读取扩展注入项目及可见性，沿用各扩展原动作与内部控件，预览样例不作为固定白名单 |
| 快速回复 | 续写／重生成之后，双对话图标；回复组、搜索、逐条运行及编辑后使用 | 快捷回复扩展的真实回复组与执行接口；保留脚本、隐藏项、上下文菜单和自动触发配置 |
| AI 帮答 | 快速回复右侧，人物＋笔图标 | `#option_impersonate`；真实生成写入原生输入框，由用户再发送 |

快速回复的主点击沿用该条目的运行定义：仅插入、发送或者执行 STscript；右侧笔图标明确表示先放入输入框编辑。预览中的「创作」组设为插入，常用组包含不实际执行的脚本示例。管理入口进入独立的快捷回复设置工作区。

菜单中移出的续写、重生成继续使用已有输入工具。插件后来添加的菜单项目保留，按原顺序追加到公共弹出框；不能因未列在样例中就丢掉。

## 聊天管理

聊天管理移至左栏信息区最上方，替换原来分散的大纲与最近对话区域。左栏上方约三分之二为信息区，下方约三分之一为九类独立设置入口。信息区依次为聊天管理、历史对话、大纲与最近五层；大纲默认折叠并明确标注占位，不提取正文标题。

聊天管理标题下常驻「新对话」「聊天文件」两个按钮，分别表示开始新对话和管理聊天文件。当前对话始终展开，淡米色整块底色、陶土文字与状态点标注正在进行；卡片内保留重命名。历史对话默认折叠。表头省略号仅收纳群聊、删除消息和关闭聊天，不重复陈列上述两个常用入口。

关闭聊天保留文件；删除聊天需单独确认并明确将删除文件。文件管理可搜索、切换、导入／导出 JSONL、重命名和删除。删除消息进入楼层选择状态，仍能阅读正文；确认、取消出现在选择工具条，不误当成删除整个聊天。群聊保留选择现有群组、新建、成员管理、转换当前聊天与原版发言规则。输入底栏与三个公共弹出框保留本轮已认可的设计。

接入映射包括 `#option_start_new_chat`、`#option_select_chat`、`#option_delete_mes`、`#option_convert_to_group`。官方 HTML 的 `#option_close_chat` 有隐藏与可见的重复 ID，适配时必须选择有效操作节点，不能直接命中第一个隐藏节点。

## 阅读与消息编辑

纸张背景连续阅读；正文仍占满中央可用宽度，左右沿用 32px 内距。消息不展示角色头像或名字。轻分隔线划分消息，操作仅保留低强调的编辑／更多按钮，悬浮或键盘进入消息后提高可见性。时间与楼层默认悬浮／聚焦显示，设置中可改为始终显示或隐藏；触屏通过操作按钮显示同一区域的信息。

用户输入默认只显示一行可展开摘要；展开是当前消息的呈现状态，不能修改「默认折叠」偏好。编辑消息时自动展开，编辑期间不允许折叠隐藏草稿。生成、发送及取消仍走原生链路，不因折叠而移除消息或隐藏生成中的最后回复。

阅读设置使用 `Type` 图标，位于正文右收纳控件的左侧。包含宋体／黑体、14–24px 字号、1.5–2.4 行距、用户默认折叠及信息显隐。字号和行距调整即时跟随；用户已确认需求指字体样式与字号。

原文编辑框使用单层圆角纸张容器，聚焦只提示外层边界；确认／复制／提示词／删除／上移／下移／取消采用同一细线图标和轻量按钮。XML、宏、脚本、附件和 Markdown 不经过富文本转换；保存／取消读取和保留精确原文。消息更多操作保留翻译、朗读、分支、检查点、附件及第三方插件注入操作。

实现只对原生消息添加呈现状态与样式：不复制消息、不重建酒馆助手 iframe、不覆盖其内部 DOM。收起、重新展开后验证 iframe 尺寸和正文滚动位置；编辑使用原版节点和保存事件。用户设定只存阅读偏好，不把聊天复制进工作台数据库。

## 独立设置工作区

独立页面占用整个工作区；顶部返回、当前类别、保存状态和适用的导入／导出，左侧九类导航，中间横向分组和完整编辑区。无多层弹窗。表单使用紧凑双列，原文区域占完整一行；更复杂的原生控件保留为整块组件，不压成 JSON 或少量字段。

资源页面复用已通过的对应编辑器。预览显示路由与容器之间的关系，资源样例字段不构成重新确认原版功能范围。正式页面所有字段依当前后端／服务商能力显示；不支持的配置显示适用说明，不假定每个后端都能使用 Chat Completion 参数。

预设、连接和世界书的独立页面管理整个资源集合。资源列表每行有独立的圆形多选框，点击名称切换编辑对象；「编辑中」表示正在编辑的资源，圆形实心／空心表示批量选中状态，两者互不替代。上方统一提供全选、已选数量、复制、导出、删除、取消选择；未选择时禁用批量动作，全选框支持部分选中的状态。选择在分组和模块切换后保留。

预览可实际复制多个示例资源及各自的本地草稿；副本选中但不会覆盖原资源。批量删除先展示数量和名称，取消保留选择；确认后移除示例，集合为空时提供新建入口。正式接入须分别处理预设、连接和世界书的原生复制／保存／删除语义，保留未知字段；删除失败逐项反馈，保留未成功资源及草稿，不能把全局状态或当前使用关系静默覆盖。

三个资源页面的批量工具栏右侧统一预留「外部编辑器」控件，目前禁用并标注「预留」。后续用于打开目录／外部编辑器及同步，不在首版假造本地目录权限，也不复制凭据。世界书继续保留资源、条目、正文、参数四区，第一列是全部世界书的管理列表。

## 接入顺序与验收

确认后先落实公共 Popover／MenuRow 与原动作迁移，再实现聊天管理，然后阅读呈现和编辑样式；独立设置按回复格式、用户设置、背景、扩展逐页接入，资源类路由复用现有编辑器。宿主适配统一提供动作能力检测、原控件挂载／释放及同步；挂载保留节点和事件，卸载恢复原位置。

设置草稿按模块与资源区分；切换模块保留草稿，离开工作区时保存／放弃／取消，保存失败保留原文并提示重试。即时保存的原生插件配置沿用其原语义，页面明确提示即时生效，不套用假的统一保存。

按钮悬浮和按压使用轻颜色／边界反馈，菜单约 160ms，勾选与选值约 180ms，内容切换约 180ms，折叠约 220ms。圆形勾选有轻微缩放和填色过渡，下拉选值有短淡入；资源、提示词和世界书条目列表保留节点，让选中背景真实过渡。分类按钮保留节点更新颜色，编辑内容短淡入；折叠区同时过渡高度和透明度。跟手拖动与字体滑块不延迟，减少动态效果偏好同时关闭 CSS 和脚本动画。焦点、悬浮、打开、选中状态分别验收，禁止内部按钮叠底或原生蓝灰下拉破坏纸张主题。

本轮检查为局部预览检查，不等同运行时功能验收。接入后在 1366×768、1440×900、1920×1080 对照确认稿，再回归快捷回复／STscript、酒馆助手、正则、附件、消息编辑、生成／取消及原生回退。

本次修订的 13 组本地预览检查通过：涵盖左栏区域比例与默认状态、三个弹出框、原文保留、聊天操作迁移、三类资源多选／复制／确认删除与空状态、分资源草稿、选择动效及减少动态效果、九类设置分组和 320／736／1024px 防溢出。另修复预览状态回传导致重复重绘的问题，避免保存状态时打断选值动画或替换输入节点。运行时功能与完整桌面视觉验收仍在接入阶段执行。

2026-10-07 接入补充：按用户最新反馈，输入底栏的菜单、扩展工具、续写、重生成、快速回复、AI 帮答、附件全部只显示图标，保留悬停提示和无障碍名称。原文编辑继续调用官方保存；官方原有宏替换行为仍会执行，工作台不额外转换原文。
