# 常用工具与记录导出工作区

2026-10-09 已接入实际工作台验证实例 `http://192.168.31.201:32012/`，复用现有纸色、陶土色、实心圆与开合动效。

## 使用入口

- 用户设置 → 常用工具：搜索、勾选、上移／下移原聊天菜单和魔法棒工具。设置沿用酒馆用户偏好保存。
- 输入工具栏 → 记录导出，或右栏分类 → 记录导出：打开右栏临时工作区。没有独立弹窗、180px 一级资源列或深度编辑页面。
- 用户设置 → 加载诊断：查看当前浏览器的启动报告，详见 [加载调查](startup-diagnostics.md)。

常用工具直接调用原生节点及其事件。作者注释与 CFG 继续嵌入完整原生表单，按需加载时不会先闪出原生浮窗。匿名插件按钮以唯一原始名称识别，菜单位置变化不会调用错工具；同名歧义入口无法固定。插件停用后保留已选项并禁用，恢复后重新可用。两个模式共用工具配置，窄输入区以「更多工具」收纳，避免多行挤占正文。

侧栏箭头图标从 20px 增至 28px，透明点击区为 36×56px。宽屏下透明的原生表情容器不再拦截输入工具栏点击；原节点保留，原生模式不受此规则影响。

## 聊天结构分析与下载

打开时读取完整 `context.chat` 的快照，包含界面尚未渲染的楼层，使用每条消息当前选中的回复。新消息或生成中的变化不会自动混入快照；点击右上刷新重新分析。切换聊天清除之前的标签、范围、搜索和结果；关闭右栏释放 Worker。

结构页按嵌套路径统计块数、涉及楼层和字符数，可搜索标签、手动增删标签或显示常见 HTML 标签。每行直接选择保留或排除，再次点击取消，同名标签的规则作用于所有路径；这两种操作不另设页面。内容页只显示筛选结果、说话者与楼层，可搜索结果或定位到原消息。

| 方式 | 行为 |
| --- | --- |
| 没有 XML 规则 | 保留范围及消息类型内的原文，XML 标签不变 |
| 为标签选择保留 | 提取完整匹配块，嵌套父子选择不重复；默认去除所选块的标签，可勾选保留标签 |
| 为标签选择排除 | 删除所选块及内容，其他原文字节保持不变 |

保留与排除可以组合，例如保留 content／after，再排除其中的 think。排除优先，包含在被排除父块里的子块也不会导出。提供「仅 content / after」与「排除 think」快捷选择。支持带属性、重复、嵌套、命名空间和 Unicode 标签。标签名区分大小写，关键词不区分大小写。未知标签、Markdown 和宏保持原文，不执行 HTML 或脚本。

解析不要求整条消息是合法 XML。未闭合或错配的排除块会从起点屏蔽至该消息末尾，同时显示结构提示；仅提取模式跳过未闭合块。注释、CDATA、处理指令和转义标签不作为结构块，代码示例中的实际 XML 标签仍可被识别。

高级选项默认收纳，包含起止楼层、用户／角色／系统消息、说话者与楼层标记、保留外层标签。下载支持 TXT 和 Markdown；无匹配内容时禁用下载。预览最多 30 条、单条 12,000 字符，下载包含所有匹配结果。原文 JSONL 备份继续调用酒馆现有导出接口；本轮不导出图片文件，也不使用模型生成摘要。

所有筛选只影响导出副本，原聊天、隐藏状态、生成上下文及用户草稿不变。分析分批执行，可以取消。快速切换筛选只接受最新结果，下载前检查结果版本。

## 验证

`npm test` 共 32 项，包含十一项解析与导出用例，覆盖组合规则、嵌套去重、属性、错配、未闭合 think、重复标签、原文保留和范围筛选。

`npm run verify:utilities` 在实际酒馆网页中检查原生工具身份和事件、设置排序与刷新恢复、输入区收纳、142 条完整聊天导出、TXT／Markdown 文件内容、聊天切换以及 10,000 条消息取消。检查 Noval 的 1024×768、1496×817、2992×1634 和 RP 的 1496×817 布局。设置和聊天写入只在测试浏览器内回放，不写共享账号。

检查图与机器报告保存在忽略入库的 `artifacts/utility-tools/`。现有布局回归继续检查侧栏、模式切换、图钉、悬浮顶栏、回复翻页、RP 圆点及动效。
